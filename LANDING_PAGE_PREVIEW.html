[04] Principles

Three rules
we don't break.

Most "AI for finance" tools wrap a chatbot around a scraping pile. InvestIQ is built differently — every figure auditable, every AI output cites sources, every line respects Indian capital-markets convention.

01 PROVENANCE

Data you can audit.

Every figure traces to a raw file path, ingestion timestamp, and parse-confidence flag. Bronze → Silver → Gold lineage from BSE/NSE/yfinance — never recomputed in the UI.

02 CITATIONS

Agents that cite sources.

11 LangGraph agents never fabricate. When data is unavailable, output is null with a reason — never guessed. Confidence + model_version + timestamp on every output.

03 INDIA-NATIVE

Built for Indian markets.

XBRL parsing, INR-native, FY/Q quarter logic, SEBI / MCA / RBI-aware. MOSPI macro feeds, BSE EFTS, NSE corporate filings — not a US tool with India bolted on.
